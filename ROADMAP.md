# Roadmap

## Next milestones

These items are planned for after the initial public release.

- Object groups / folders (hierarchy, visibility toggles, and organization in the object browser)
- Probe + measurement tools (distance/angle/intersection-style measurements and persistent pins)
- Advanced constraints (more constraint modes with safer editing affordances)
- Animation timeline (parameter animation, play/pause/loop, and related export)
- Collaboration/backend path (future option for multi-user workflows)
- IndexedDB / remote persistence upgrade (to expand storage reliability and capacity)
